# Embroidery faces

Web fonts the configurator draws the form's embroidered text with
(glove-engine.js, drawText), standing in for SSK's own lettering:

| SSK font | Face | Source |
|---|---|---|
| Block | Barlow Condensed 700 | https://fonts.google.com/specimen/Barlow+Condensed |
| Script | Yellowtail 400 | https://fonts.google.com/specimen/Yellowtail |
| Brush | Kaushan Script 400 | https://fonts.google.com/specimen/Kaushan+Script |
| Kanji | not previewed: SSK stitches it in Japanese characters | |

All three are under the SIL Open Font License 1.1. These are the Latin
subsets as served by Google Fonts on 24 September 2026; the single-file
build inlines them (bundle.py).
