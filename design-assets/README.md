# SSK header logo

`SSK-Logo.pdf` is the original logo supplied by Scott on 19 October 2026 for the
configurator header. SHA-256: `4b421f20e590cb625a21d3476a0cd194bcc7f088943860334df8bae3c48ab5c9`.

The runtime asset is `../glove_builder/customiser/ssk-logo.svg`. It retains the
PDF's five vector paths, RGB fills and even-odd fill rule, with the original
page size, a translation for the PDF MediaBox origin (-1, -1), and the
PDF-to-SVG coordinate flip. No shapes were generated or
redrawn. The header provides a light background for the original dark/red logo.

The original PDF is retained here for provenance; only the small SVG is included
in the static website package.
